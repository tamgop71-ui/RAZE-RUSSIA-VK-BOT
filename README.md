# RAZE RUSSIA VK BOT

Самостоятельная PHP 8.2 реализация бота сообщества ВКонтакте с Long Poll. Это не оригинальный код Pxolly, а собственный проект с похожими категориями функций.

## Требования
- PHP 8.2 CLI
- расширения `curl`, `pdo_sqlite`, `mbstring`
- токен сообщества ВКонтакте
- включённые сообщения сообщества и доступ к Long Poll API
- для удаления сообщений/кика нужны соответствующие права бота в беседе

## Установка на Bothost
1. Загрузите содержимое ZIP в свой проект/репозиторий Bothost.
2. Укажите запуск: `php bot.php` (или используйте Dockerfile, если панель собирает Docker).
3. В настройках переменных окружения добавьте:
   - `VK_TOKEN` — ключ доступа сообщества, не пользовательский токен.
   - `VK_GROUP_ID` — числовой ID сообщества без минуса.
   - `OWNER_IDS` — ваш числовой VK ID; можно несколько через запятую.
   - `TZ=Europe/Moscow`
   - `DB_PATH=/app/data/raze.sqlite` для Docker; без Docker можно `data/raze.sqlite`.
4. Убедитесь, что в контейнере установлены `curl`, `pdo_sqlite`, `mbstring`.
5. Запустите контейнер и проверьте логи. Должны появиться `Long Poll connected; message_new enabled.`
6. Напишите `/ping` со своего аккаунта в сообщениях сообщества или в беседе, куда добавлено сообщество.

Если панель не поддерживает Docker и не даёт PHP 8.2 CLI с нужными расширениями, этот контейнерный вариант не запустится без настройки образа. Не размещайте токен в публичном репозитории.

## Команды
Префиксы: `/`, `!`, `.`, `,` — например `/ping` или `!ping`.

### Общие
- `/ping`, `/help`, `/myid`, `/role`, `/roles`, `/admins`

### Репорты
- `/report текст` — создать репорт
- `/reports` — список открытых репортов (помощник и выше)
- `/close ID` — закрыть репорт

### Модерация
- `/warn ID причина` — предупреждение (модератор+)
- `/unwarn ID` — снять последнее активное предупреждение
- `/mute ID 10m причина` — мут в базе и удаление новых сообщений пользователя, если у бота есть права
- ответьте на сообщение командой `/mute 10m причина`
- `/unmute ID`
- `/ban ID 1d причина` — внести в бан-лист; в беседе бот также попытается удалить пользователя
- `/unban ID` — убрать из внутреннего бан-листа
- `/kick ID` — удалить из беседы

### Роли и данные
- `/setrole ID помощник|модератор|администратор|ст.администратор`
- `/delrole ID`
- `/nick ID игровой_ник`
- `/logs` или `/logs ID`

### Владелец
- `/addws ID` — выдать супердоступ
- `/delws ID` — снять супердоступ

ID можно указывать числом или отвечать командой на сообщение пользователя (если поддерживается типом команды). Для модерационных команд безопаснее указывать числовой ID явно.

## Важные ограничения
- VK API не позволяет боту произвольно запретить пользователю писать в беседе через универсальную команду. Здесь мут реализован как внутренняя отметка с попыткой удалять новые сообщения; результат зависит от прав и возможностей VK API.
- `/ban` ведёт внутренний бан-лист и пытается удалить пользователя из текущей беседы. Это не глобальный бан аккаунта VK и не автоматический бан на игровом сервере.
- При трёх предупреждениях бот сообщает администрации, но не отзывает роль автоматически.
- Список `OWNER_IDS` — главный уровень доступа, его нельзя выдать командой в чате.
- Реальные возможности проверяются только после подключения к вашему сообществу и тестирования на Bothost. Не публикуйте токен.

## Диагностика
- `VK API 5`: токен не имеет нужного доступа или невалиден.
- `VK API 7/15`: нет прав у токена/сообщества или доступ закрыт.
- `VK API 100`: проверьте ID, параметры API и доступность метода.
- Контейнер перезапускается: посмотрите первые строки лога; чаще всего не заданы `VK_TOKEN`, `VK_GROUP_ID` или нет PHP-расширений.
