# RAZE RUSSIA VK BOT

Самостоятельная PHP 8.2 реализация бота сообщества ВКонтакте с Long Poll.  
Улучшенная версия: исправлены баги, добавлена защита от флуда, автоочистка истёкших мутов/банов, новые команды и стабильный Long Poll.

## Требования
- PHP 8.2 CLI
- расширения `curl`, `pdo_sqlite`, `mbstring`
- токен сообщества ВКонтакте (с правами на сообщения и управление беседой)
- включённые сообщения сообщества и доступ к Long Poll API
- для удаления сообщений / кика нужны соответствующие права бота в беседе

## Установка на Bothost / Docker
1. Загрузите содержимое в проект.
2. Запуск: `php bot.php` или через Docker.
3. Переменные окружения:
   - `VK_TOKEN` — ключ доступа **сообщества** (не пользовательский)
   - `VK_GROUP_ID` — числовой ID сообщества **без минуса**
   - `OWNER_IDS` — ваш числовой VK ID (можно несколько через запятую)
   - `TZ=Europe/Moscow`
   - `DB_PATH=/app/data/raze.sqlite` (для Docker) или `data/raze.sqlite`
4. Убедитесь, что в контейнере есть `curl`, `pdo_sqlite`, `mbstring`.
5. В логах должно появиться: `Long Poll connected; message_new enabled.`
6. Напишите `/ping` со своего аккаунта.

**Не публикуйте токен в открытых репозиториях.**

## Команды
Префиксы: `/` `!` `.` `,`  
Можно отвечать на сообщение пользователя (target берётся из ответа).

### Общие
| Команда | Описание |
|---------|----------|
| `/ping` | Проверка работы бота |
| `/help` | Справка (показывает команды по вашему уровню) |
| `/myid` | Ваш VK ID и Peer ID |
| `/role` | Ваша роль и ник |
| `/roles` | Список всех ролей и приоритетов |
| `/info [ID]` | Информация о пользователе (роль, варны, мут, бан, ник) |
| `/nick ID ник` | Установить игровой ник |
| `/delnick ID` | Удалить ник |
| `/report текст` | Создать жалобу (админы получают уведомление) |
| `/status` | Статус бота |

### Помощник+ (приоритет ≥ 20)
| Команда | Описание |
|---------|----------|
| `/reports` | Список открытых репортов |
| `/close ID` | Закрыть репорт |
| `/admins` | Список администрации |

### Модератор+ (приоритет ≥ 40)
| Команда | Описание |
|---------|----------|
| `/warn ID причина` | Выдать предупреждение (3 = уведомление) |
| `/unwarn ID` | Снять последнее активное предупреждение |
| `/warns ID` | История предупреждений |
| `/mute ID 10m причина` | Мут (удаляет сообщения) |
| `/unmute ID` | Снять мут |
| `/kick ID` | Удалить из беседы |
| `/logs [ID]` | Лог действий |

### Администратор+ (приоритет ≥ 60)
| Команда | Описание |
|---------|----------|
| `/ban ID 1d причина` | Бан + кик из беседы |
| `/unban ID` | Снять бан |
| `/setrole ID роль` | Выдать роль |
| `/delrole ID` | Сбросить роль |
| `/stats` | Статистика бота |

### Владелец / Супердоступ
| Команда | Описание |
|---------|----------|
| `/addws ID` | Выдать супердоступ |
| `/delws ID` | Снять супердоступ |
| `/say текст` | Сообщение от имени бота |
| `/clearlogs` | Очистить audit-лог |

### Роли
- **Владелец** (OWNER_IDS) — полный доступ
- **Супердоступ** — почти полный доступ
- **Ст. администратор** (80)
- **Администратор** (60)
- **Модератор** (40)
- **Помощник** (20)
- **Участник** (0)

### Длительность
`30s` `10m` `2h` `1d` `1d12h` `perm` / `навсегда`

## Что исправлено и добавлено
- Исправлен кривой ключ в `groups.setLongPollSettings` (` Donut`)
- Корректный парсинг длительности (включая комбинированный `1d2h`)
- Правильная обработка target из ответа на сообщение
- Автоматическая очистка истёкших мутов и банов
- Бан теперь блокирует сообщения + пытается кикнуть
- Антифлуд (временный мут при спаме команд)
- Уведомление администрации о новых репортах
- Команды `/info`, `/warns`, `/stats`, `/status`, `/say`, `/delnick`, `/clearlogs`
- Индексы в SQLite для скорости
- Стабильный Long Poll с авто-обновлением ключей и backoff
- Защита от выдачи роли выше своей
- Игнорирование сообщений от самого сообщества

## Важные ограничения VK
- Бот не может «официально» замутить через API — мут реализован удалением сообщений (нужны права администратора беседы).
- `/ban` — внутренний бан-лист + попытка кика. Это не глобальный бан аккаунта VK.
- При 3 предупреждениях бот только уведомляет, роль не снимается автоматически.
- `OWNER_IDS` нельзя выдать командой в чате.

## Диагностика
- `VK API 5` — невалидный токен
- `VK API 7/15` — нет прав у токена/сообщества
- `VK API 100` — неверные параметры
- Контейнер перезапускается — проверьте `VK_TOKEN`, `VK_GROUP_ID` и расширения PHP
