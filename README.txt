ЧТО ПРОВЕРЕНО:
1. bot.php проходит PHP syntax check.
2. Все таблицы, которые создаёт bot.php, присутствуют в database.sql.
3. Дублирующихся case-меток в основном switch нет.
4. Команды из req сопоставлены с обработчиками; английские aliases переводятся в реальные case.
5. Long Poll перезапускается после failed/сетевого сбоя.
6. Ошибка одной команды больше не должна останавливать обработку следующих обновлений.
7. VK API использует cURL с таймаутами и повторной попыткой, с fallback на HTTP stream.
8. MySQL подключение повторяется при временном недоступном сервере вместо мгновенного завершения контейнера.
9. Добавлена !диагностика / !health / !diag.
10. !help, !помощь, !команды и их английские варианты имеют отдельный гарантированный путь.
11. !unityinfo обновляет название бесед через VK API и использует резервный вариант Беседа #ID.
12. При выходе/исключении пользователя сбрасываются локальные роль, ник, иммунитет и opt-out упоминаний.
13. При исключении самого бота его беседа помечается неактивной.
14. Кнопки объединений и репортов обрабатываются через message_event.
15. MySQL схема автоматически создаёт отсутствующие таблицы и мигрирует несколько старых колонок.

ПЕРВЫЙ ЗАПУСК:
1. Загрузить содержимое архива в Bothost.
2. Оставить существующие ENV-переменные с VK_TOKEN и паролем БД.
3. Убедиться, что MYSQL_HOST = 80.242.59.112 для Bothost.
4. Пересобрать контейнер.
5. Перезапустить контейнер.
6. Проверить лог запуска.

   !help
   !версия
   !диагностика

ТРЕБОВАНИЯ VK:
- включён Community Long Poll;
- у сообщества есть доступ к сообщениям;
- для кика/бана бот должен иметь соответствующие права в беседе;
- для callback-кнопок должны приходить message_event.

ЛОГИКА АВАРИЙНОГО ВОССТАНОВЛЕНИЯ:
- VK API: до 2 попыток запроса;
- Long Poll: повторное получение сервера после failed;
- MySQL: повтор подключения каждые 10 секунд при временной ошибке;
- исключение одной команды не завершает основной цикл бота.

LIVE-ПРОВЕРКА:
Полностью проверить реальные права VK, доставку Long Poll и действия конкретного сообщества из контейнера без запуска на вашем Bothost невозможно. Поэтому после установки обязательно выполнить 4 команды из раздела ПЕРВЫЙ ЗАПУСК.
