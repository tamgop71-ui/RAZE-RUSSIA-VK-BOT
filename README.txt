RAZE RUSSIA VK BOT v6.0.0

Основные исправления:
- Супер-доступ через /addws [ID], ответ или без цели (сам автор).
- Супер-доступ имеет приоритет 100 и гарантированно проходит проверки супер-команд.
- /sysrole без цели назначает роль автору команды.
- Системный бан/мут не блокирует супер-пользователю команды восстановления.
- Цели поддерживают reply, [id123|Имя], id123, @id123 и vk.com/id123.
- Полноценная система репортов: /report, /reports, /getreport, /getdialog, /reportmsg, /closereport.
- Иерархия наказаний учитывает системный приоритет цели.

Запуск: php bot.php
Переменные: VK_TOKEN, VK_GROUP_ID, OWNER_IDS, TZ, MYSQL_HOST, MYSQL_DATABASE, MYSQL_USER, MYSQL_PASSWORD, MYSQL_PORT.
Не помещайте токен VK и пароль БД в GitHub.
