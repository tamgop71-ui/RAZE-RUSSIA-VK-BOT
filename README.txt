RAZE RUSSIA VK BOT — ULTIMATE

1. Замените bot.php.
2. НЕ удаляйте data/raze.sqlite.
3. Перезапустите контейнер Bothost.
4. Бот должен иметь права администратора беседы и управление участниками.

Изменения:
- Префиксы команд: ! / . , # ?
- Автонастройка при добавлении бота в беседу.
- !звезда / !снятьзвезду / !звезды.
- 3-й активный варн автоматически пытается исключить пользователя.
- !выдатьденьги [ID] [сумма] — только супер-доступ (уровень 100).
- /report текст — сохраняется и отправляется OWNER_IDS + superusers в ЛС.
- Имена пользователей в ответах — кликабельные VK-ссылки.
- Объединения: !объединение создать [название], !объединение добавить [ID], !объединение список, !объединение удалить [ID].
