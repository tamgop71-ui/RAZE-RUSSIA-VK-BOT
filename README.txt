RAZE RUSSIA VK BOT — AUDITED BUILD

Что исправлено:
1. При добавлении бота в беседу:
   - создателю беседы автоматически ставится роль 100 «Владелец»;
   - пользователю, который добавил бота, ставится роль 80 «Ст. администратор», если это другой человек.
2. Добавлена первичная настройка chat_settings.
3. !команды / !помощь теперь открывают структурированное меню с кнопками разделов, а не огромный список.
4. Исправлен разбор команд: поддерживаются ! / . , # ? и основные английские алиасы.
5. Исправлены назначения ролей: нельзя выдать роль равную или выше своей.
6. !admin / !gadmin теперь действительно назначают роль 80.
7. !pin / !unpin теперь реально вызывают VK API, а не просто пишут сообщение.
8. Муты, баны и режим тишины проверяются на каждом новом сообщении; сообщения нарушителей удаляются, активный бан дополнительно пытается исключить пользователя из беседы.
9. !givemoney поддерживает отрицательную сумму.
10. HTTP/VK запросы переведены на cURL с fallback, таймаутами и повторными попытками.
11. Long Poll использует тот же устойчивый HTTP-транспорт.
12. Dockerfile устанавливает pdo_sqlite, mbstring и curl — обязательные расширения для этой версии.

Установка на Bothost:
- VK_TOKEN, VK_GROUP_ID, OWNER_IDS, TZ задаются через переменные окружения.
- VK_TOKEN не хранить в архиве и не публиковать.
- Папка data должна быть доступна для записи: там создаётся raze.sqlite.
- После загрузки/сборки перезапустите контейнер.

Первый тест:
!пинг
!команды
!диагностика (если команда присутствует в вашей сборке)

ВАЖНО:
Если бот уже был добавлен в старую беседу до этой версии, событие добавления повторно не придёт. Для такой беседы используйте !sync, а затем !owner ID создателя и !admin ID администратора при необходимости.
